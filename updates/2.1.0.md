## Der Fehler

Der Optionen-Knopf war auf dem Desktop blass und ließ sich nicht bedienen. Er war
nicht abgeschaltet, sondern verdeckt:

| Element | Regel aus 2.0.0 | Fläche bei 1920 px |
|---|---|---|
| `#rennAuswahl` | `position:fixed; top:8; left:8; right:96; z-index:999` | x = 8 … 1824 |
| `#optionsBtn` (≥768 px) | `top:10; right:120; z-index:999` | x ≈ 1690 … 1800 |
| `#taktikBtn` | `top:10; right:10; z-index:999` | x ≈ 1824 … 1910 |

Beide haben `z-index:999`. Bei gleichem Wert entscheidet die Reihenfolge im
Dokument, und `#rennAuswahl` steht in `index.html` in Zeile 225, der Knopf in
Zeile 89 — die Leiste lag also darüber. Ihr Hintergrund
`rgba(255,255,255,0.92)` erzeugte den blassen Eindruck, ihre Fläche fing die
Tipper ab.

Der Taktik-Knopf beginnt vier Pixel hinter dem Leistenende und blieb deshalb
bedienbar. Auf dem Handy sitzen beide Knöpfe unten — dort gab es die
Überdeckung nie.

Zwei weitere Folgen derselben Ursache: der erste Chip lag hinter der
Leaflet-Zoomleiste (die hat `z-index:1000`), und `#raceClock` legte sich auf dem
Handy über die Chips.

## Was 2.1.0 daraus macht

Statt die Leiste ein Stück schmaler zu machen, fällt sie ganz weg. Chipleiste und
Rundenkasten trugen dieselbe Aussage — Farbe, Kürzel, Rennname — in zwei Kästen
übereinander. Ab jetzt gibt es **eine Rennleiste** in `#raceClock`, mit einer
Zeile je laufendem Rennen:

```
● U15m 🚗    − Noch 2 Runden +
● U15w       − 🏁 Zielrunde  +
```

Die Zeile ist zugleich die Auswahl. Tippen blendet das Rennen aus und wieder ein,
langes Tippen (oder Rechtsklick) setzt das Rennen, hinter dem man selbst
herfährt. Beides funktioniert wie vorher an den Chips; es ist nur an die Zeile
gewandert.

**Der Veranstaltungsname entfällt.** „U15m · DM MZF" wird zu „U15m". Bei
gleichzeitig laufenden Rennen ist die Veranstaltung ohnehin dieselbe, und auf
einem Handydisplay kostete sie die halbe Zeile.

**Abgewählte Rennen behalten ihre Zeile**, blass und ohne Rundenzähler. Ohne sie
gäbe es keinen Weg zurück — die Chipleiste, über die man ein Rennen wieder
einblendete, gibt es ja nicht mehr.

**Die Leiste beginnt bei `left:52px`**, also rechts neben der Zoomleiste, und
endet auf dem Desktop bei `right:250px`, also vor der Knopfreihe.

**Der Kasten fängt keine Tipper mehr ab.** `pointer-events` liegt nur auf den
Zeilen selbst; die Knöpfe stehen auf `z-index:1002` und damit über Leiste (999)
und Leaflet-Zoomleiste (1000). Eine künftige Überdeckung kann keinen Knopf mehr
lahmlegen — das ist der eigentliche Riegel gegen diese Fehlerklasse.

## Taktik-Streifen

Der Reiter je Rennen aus 2.0.0 entfällt. Er war irreführend: er schaltete die
Beschriftung um, nicht die Datenquelle. `groups` gibt es im Server genau einmal
und gehört dem Leitrennen — ein Tipp auf „U15w" zeigte weiterhin die Gruppen von
U15m, nur mit fremdem Kürzel darüber. Genau das ist im Rennen die gefährlichere
Variante.

An seiner Stelle steht ein Kopf mit Farbpunkt und Kürzel **des Leitrennens**,
also des Rennens, dessen Taktik der Streifen tatsächlich zeigt. Bei einem einzigen
laufenden Rennen entfällt er ganz: dann ist nichts zu verwechseln. Das eigene
Rennen wird jetzt ausschließlich über die Rennleiste oben gesetzt.

**Damit ist die Anzeige ehrlich, aber noch nicht das, was der Streifen zeigen
soll.** Solange `groupsByRace` im Server fehlt, kann der Streifen die Taktik eines
Nicht-Leitrennens nicht darstellen. Das bleibt die nächste Baustelle.

## Zwei stille Korrekturen

**Die Rennleiste hängt nicht mehr an der Startzeit.** Bis 2.0.0 stand ganz oben
in `updateRaceClock()` ein `if (!raceStartMsClient()) return hidden;` — ein
laufendes Rennen ohne bestätigten oder geplanten Startschuss hatte damit keine
Leiste und, seit die Auswahl dort hängt, auch keine Rennauswahl. Die Prüfung gilt
jetzt nur noch für den alten Fahrtzeit-Zweig.

**Die Leiste wird nur bei echter Änderung neu gebaut.** `updateRaceClock()` läuft
im Sekundentakt (`setInterval` in `core/app.js`). Ein Neuaufbau mitten im langen
Tippen hätte das Element samt Timer weggeworfen, und die Auswahl des eigenen
Rennens wäre Glückssache gewesen. `letzteLeiste` vergleicht das erzeugte HTML und
lässt den DOM sonst stehen.

`loadActiveInfo()` wie bisher den Steckbrief des Leitrennens daraus; die
Rennleiste zeigt dann eine Zeile.

## Rollback

Alle fünf Dateien zusammen zurückrollen. Keine Schemaänderung, keine
Datenmigration, keine Serverbeteiligung. Ein Rollback stellt die Chipleiste samt
Überdeckungsfehler wieder her — auf dem Handy fällt das nicht auf, auf dem
Desktop wieder.

Ein Teilrollback nur von `css/app.css` ist **nicht** zulässig: `index.html` und
`map/map.js` erzeugen dann Zeilen, für die es keine Regeln mehr gibt.

// Korrekturknoepfe. Die Knoepfe tragen die Renn-ID mit sich - bei zwei
// Rennen darf kein Zweifel bestehen, welche Zaehlung ein Tipp
// verstellt.
//
// Ab 2.1.0 ist die Zeile zugleich die Auswahl: tippen blendet das
// Rennen aus und wieder ein, langes Tippen setzt das eigene Rennen.
// Ein abgewaehltes Rennen behaelt seine Zeile - sonst gaebe es keinen
// Weg zurueck.
//
// mehrere: erst ab zwei laufenden Rennen gibt es etwas zu waehlen. Bei
// einem bleibt die Zeile ein reiner Rundenstand, wie bis 2.0.0.
function rennZeile(raceId, mehrere) {
  const s = steckbriefe[raceId];
  if (!s) return '';
  // Ohne Veranstaltungsnamen: der ist bei allen gleichzeitig laufenden
  // Rennen derselbe und kostet auf einem Handydisplay die halbe Zeile.
  const lbl = s.name || raceId;

function updateRaceClock() {
  const el = document.getElementById('raceClock');
  if (!el) return;
  const s = raceStartMsClient();
  if (!s) { el.classList.add('hidden'); return; }
  const sek = Math.max(0, Math.floor((Date.now() - s.ms) / 1000));
  const zeit = `${Math.floor(sek / 3600)}:${String(Math.floor(sek / 60) % 60).padStart(2, '0')}`
             + `:${String(sek % 60).padStart(2, '0')}`;
  const avg = feldSchnitt();
  // Ab 2.0 zeigt die Leiste nur noch die Runde, dafuer je sichtbarem
  // Rennen eine Zeile. Fahrtzeit und Feldschnitt sind entfallen: die
  // Uhrzeit steht ohnehin auf dem Geraet, und bei zwei Rennen mit
  // verschiedenen Startzeiten waere eine gemeinsame Fahrtzeit sinnlos.
  // Der Rundenzaehler bleibt, weil an ihm die Korrekturknoepfe haengen -
  // ohne sie liesse sich eine falsch gezaehlte Runde bis zum Rennende
  // nicht mehr richtigstellen.
  const sicht = sichtbareRennenListe();
  if (sicht.length) {
    el.innerHTML = sicht.map(id => rennZeile(id)).join('');
    el.querySelectorAll('.rcLap').forEach(b => {
      b.addEventListener('click', ev => {
        ev.stopPropagation();
        adjustLap(Number(b.dataset.lap), b.dataset.race);
      });
    });
    el.classList.remove('hidden', 'geplant');
    el.classList.toggle('mehrfach', sicht.length > 1);
    el.title = 'Runde je Rennen \u2013 \u00B1 korrigiert die Z\u00E4hlung';
    return;
  }
  // Zielrunde statt "4/4": im Auto zaehlt die Aussage, nicht die Zahl.
  let runde = '';

### Hunk 9 — `race/taktik-ui.js` · Reiter durch Kopfzeile ersetzt

**ALT** (21 Zeilen)

```js
// Ab 2.0 koennen mehrere Rennen gleichzeitig laufen. Der Streifen ist
// 70 px breit und sitzt am rechten Rand - auf einem Handy waere kein
// Platz fuer zwei davon nebeneinander. Deshalb bleibt es bei einem
// Streifen mit einem Reiter je Rennen darueber.
//
// Der Reiter folgt dem Rennen, hinter dem der Nutzer selbst herfaehrt
// (meinRaceId). Im Regelfall muss also gar nicht umgeschaltet werden.
function renderStripReiter() {
  if (typeof sichtbareRennenListe !== 'function') return '';
  const ids = sichtbareRennenListe();
  if (ids.length < 2) return '';
  const mein = meinRaceId();
  return '<div class="stripTabs">' + ids.map(id => {
    const s   = (typeof steckbriefOf === 'function') ? steckbriefOf(id) : null;
    const lbl = (typeof raceLabel === 'function') ? raceLabel(id, true) : id;
    const an  = (id === mein);
    return `<div class="stripTab${an ? ' on' : ''}" data-race="${id}"`
         + `${an && s && s.farbe ? ` style="border-bottom-color:${s.farbe}"` : ''}>`
         + `${escH(String(lbl).slice(0, 5))}</div>`;
  }).join('') + '</div>';
}
```

// Ab 2.0 koennen mehrere Rennen gleichzeitig laufen. Der Streifen ist
// 70 px breit und sitzt am rechten Rand - auf einem Handy waere kein
// Platz fuer zwei davon nebeneinander.
//
// Bis 2.0.0 stand darueber ein Reiter je Rennen. Das war irrefuehrend:
// der Reiter schaltete nur die Beschriftung um, nicht die Datenquelle.
// groups gibt es im Server genau einmal und gehoert dem Leitrennen -
// ein fremdes Kuerzel ueber echten Gruppendaten waere im Rennen die
// gefaehrlichere Variante.
//
// Ab 2.1.0 steht deshalb nur noch ein Kopf da, und zwar mit dem Rennen,
// dessen Taktik der Streifen tatsaechlich zeigt. Bei einem einzigen
// laufenden Rennen entfaellt er: dann ist nichts zu verwechseln.
function renderStripReiter() {
  if (typeof laufendeRennen !== 'function' || laufendeRennen() < 2) return '';
  const id = (typeof activeInfo === 'object' && activeInfo) ? activeInfo.raceId : null;
  if (!id) return '';
  const s     = (typeof steckbriefOf === 'function') ? steckbriefOf(id) : null;
  const farbe = (s && s.farbe) ? s.farbe : '#607d8b';
  const lbl   = (s && s.name) ? s.name : id;
  return `<div class="stripKopf" style="border-bottom-color:${farbe}"`
       + ` title="Taktik des Leitrennens">`
       + `<span class="stripKopfP" style="background:${farbe}"></span>`
       + `${escH(String(lbl).slice(0, 6))}</div>`;
}
