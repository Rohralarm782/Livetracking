## Zweck

Der Taktik-Streifen am rechten Rand zeigte jede Gruppe als eigene Kachel. Am
Renntag standen neun Gruppen darin (U17m, 05.09. 12:45): der Streifen lief oben
und unten aus dem Bild, und im fahrenden Auto war nicht mehr auf einen Blick zu
erkennen, wo das Feld steht.

Ab 2.11.0 zeigt der Streifen **höchstens fünf Gruppen einzeln**; aufeinander
folgende Gruppen dahinter werden zu einer Kachel **„Rest"** zusammengefasst.

### Regeln

1. **Grenze:** `STRIP_MAX = 5`. Bewusst eine Konstante in `race/taktik-ui.js`,
   keine Einstellung im Menü — eine Schraube mehr löst das Problem nicht.
2. **Hauptfeld bleibt immer sichtbar.** Liegt es hinter Platz 5 (viele
   Ausreißer), werden nur vier Gruppen davor gezeigt, dann das Hauptfeld. Es
   können dadurch zwei Rest-Kacheln entstehen: eine vor, eine hinter dem
   Hauptfeld. Die Regel für das Hauptfeld ist dieselbe wie in `mainGroupIdx()`
   und im Server: ausdrücklicher `main`-Marker, sonst die letzte Gruppe.
3. **Erst ab zwei eingeklappten Gruppen.** Bei sechs Gruppen bleibt alles
   einzeln stehen: ein „Rest", der genau eine Gruppe verdeckt, braucht dieselbe
   Zeile und nimmt nur Name und Farbe weg. Gleiches gilt für einzelne Blöcke,
   die beim Vorziehen des Hauptfelds entstehen.
4. **Inhalt der Rest-Kachel:** grauer Punkt, „Rest", groß die Summe der Fahrer
   (DSQ/DNF zählen wie überall nicht mit), klein darunter die Zahl der Gruppen
   („4 Gr."). Der Tooltip nennt die eingeklappten Gruppen mit Fahrerzahl.
5. **Abstände bleiben exakt.** Die Regel „der Wert an der Linie gehört zu dem,
   was darunter kommt" ist unverändert; sie zeigt jetzt auf die erste Gruppe des
   nächsten Postens. Da ein Rest immer **aufeinanderfolgende** Gruppen abdeckt
   und `gap` seit 2.10.0 der Rückstand auf die Gruppe davor ist, stimmt der
   angezeigte Wert weiterhin genau — er ist der Abstand von der letzten Gruppe
   des vorigen Postens zur ersten Gruppe des nächsten. Nicht mehr sichtbar sind
   die Abstände **innerhalb** eines Rests.

### Bewusst nicht geändert

- Die Taktik-Vollansicht zeigt weiterhin **alle** Gruppen einzeln; dort wird
  bearbeitet, dort darf nichts verdeckt sein.
- Keine Änderung an Server, Garmin-Text oder Android Auto: `renderStrip()` ist
  reine Anzeige, die Gruppendaten bleiben unangetastet.
- Kein Aufklappen per Tipp: ein Tipp auf den Streifen öffnet weiterhin die
  Taktik — dort steht ohnehin alles.

// Problem nicht, sie verschiebt es.
const STRIP_MAX = 5;

// Teilt die Gruppen in Posten: einzeln gezeigte Gruppen und
// zusammengefasste Bloecke ("Rest"). Ein Block deckt immer
// AUFEINANDERFOLGENDE Gruppen ab - das ist die Bedingung dafuer, dass
// die Abstaende stimmen bleiben: gap ist seit 2.10.0 der Rueckstand auf
// die Gruppe davor, und zwischen zwei Posten ist das genau der Wert der
// ersten Gruppe des naechsten Postens.
function stripPosten(list) {
  // Ein Rest, der genau eine Gruppe verdeckt, braucht dieselbe Zeile
  // und nimmt nur Name und Farbe weg. Deshalb wird erst eingeklappt,
  // wenn mindestens zwei Gruppen darin landen.
  if (list.length <= STRIP_MAX + 1) return list.map(g => ({ rest: false, gs: [g] }));
  // Das Hauptfeld bleibt immer sichtbar: bei vielen Ausreissern rutscht
  // es hinter Platz 5 und waere sonst ausgerechnet die Gruppe, die im
  // Rest verschwindet. Gleiche Regel wie im Server und in
  // mainGroupIdx(): ausdruecklicher Marker, sonst die letzte Gruppe.
  let mi = list.findIndex(g => g && g.main === true);
  if (mi < 0) mi = list.length - 1;
  const sicht = new Set();
  for (let i = 0; i < STRIP_MAX; i++) sicht.add(i);
  if (!sicht.has(mi)) { sicht.delete(STRIP_MAX - 1); sicht.add(mi); }
  const posten = [];
  list.forEach((g, i) => {
    const letzter = posten[posten.length - 1];
    if (!sicht.has(i) && letzter && letzter.rest) { letzter.gs.push(g); return; }
    posten.push({ rest: !sicht.has(i), gs: [g] });
  });
  // Wird das Hauptfeld nach vorne geholt, koennen zwei Bloecke
  // entstehen - einer davor, einer dahinter. Enthaelt einer davon nur
  // eine Gruppe, wird sie wieder ausgeschrieben (gleicher Grund wie oben).
  posten.forEach(p => { if (p.rest && p.gs.length === 1) p.rest = false; });
  return posten;
}
