## Neu in der Bedienung

- **Gruppennamen richten sich nach der Fahrreihenfolge.** Wer wie heisst,
  entscheidet die Position im Verhaeltnis zum Hauptfeld-Marker. Nach jedem
  Aufteilen, Zusammenfuehren, Loeschen und Umsetzen des HF stimmen die Namen
  von selbst.

  | Lage | Name |
  |---|---|
  | vorderste Gruppe, sofern nicht selbst HF | Spitzengruppe |
  | zwischen Spitze und HF, eine Gruppe | Verfolger |
  | zwischen Spitze und HF, mehrere | Verfolger 1, Verfolger 2 … von vorne |
  | HF-Gruppe | Hauptfeld |
  | hinter dem HF, eine Gruppe | Gruppetto |
  | hinter dem HF, mehrere | Gruppetto 1, Gruppetto 2 … |

  Die Ziffer kommt erst ab zwei Gruppen im selben Abschnitt: bei genau einem
  Verfolger waere „Verfolger 1\" eine Nummerierung ohne Reihe.

- **Ein selbst eingetippter Name bleibt stehen.** Wer eine Gruppe „Ausreisser
  Meier\" nennt, behaelt sie so — auch wenn sie spaeter nach hinten rutscht.

- **Namensfeld leeren stellt die Automatik wieder her.** Bisher hat ein leeres
  Feld nichts bewirkt; jetzt ist es der Rueckweg aus einem eigenen Namen.

- **Kurzer Hinweis „✎ Gruppen neu benannt\"**, aber nur wenn tatsaechlich ein
  Name gewechselt hat. Beim blossen Fahrerschieben bleibt es still.

- **Beim Zusammenfuehren** verschwindet die Quellgruppe wie bisher komplett,
  ihr Name geht mit. Die Zielgruppe behaelt ihren.

## Erster Start nach dem Deploy

Beim ersten Speichern der Taktik werden Gruppen, die noch alte automatische
Namen tragen, auf ihren Positionsnamen gezogen — betroffen sind
`Spitze 2`, `Vorne`, `Ausrueszer`, `Nachzuegler`, `Feld 2`, `Hinten`,
`Neue Gruppe` und `Gruppe N`. Das ist so gewollt: es waren Namen, die das
System selbst vergeben hat. Von Hand gesetzte Namen sind nicht betroffen.

Kein Schema, kein Datenformat, keine Migration. Ein Rollback ist ein
Zurueckspielen der beiden JS-Dateien.

## Geprueft

Jeder Patch mit `str.count(old) == 1` erzwungen, sechs von sechs eindeutig.
`node --check` auf beiden JS-Dateien bestanden, `version.json` als JSON
geparst. Funktionsbestand in `taktik.js` 36 → 38, Zugaenge `istAutoName` und
`benenneGruppenNeu` — **keine Funktion verloren**. `diff -rq` gegen den
Originalstand meldet genau diese drei Dateien, alle uebrigen bytegleich.

Zwoelf Verhaltenstests der Benennungslogik gruen:

- HF hinten mit einem Verfolger → `Spitzengruppe · Verfolger · Hauptfeld`
- HF hinten mit drei Verfolgern → `Spitzengruppe · Verfolger 1 · Verfolger 2 ·
  Verfolger 3 · Hauptfeld`
- ein Gruppetto ohne Ziffer, zwei mit Ziffer
- HF auf der vordersten Gruppe → keine Spitzengruppe, alles dahinter Gruppetto
- kein HF-Marker gesetzt → letzte Gruppe gilt, wie im Server auch
- einzige Gruppe → Hauptfeld
- `Ausreisser Meier` bleibt stehen, `Spitze 2` und `Nachzuegler` werden
  aufgeraeumt
- leerer Name gilt als automatisch
- unveraenderter Stand liefert Rueckgabe 0, also kein Hinweis

Regex-Trennschaerfe geprueft: `Verfolgerteam`, `Spitzengruppe A`,
`Ausreisser Meier` und `HF` gelten korrekt als Eigennamen und bleiben stehen.
