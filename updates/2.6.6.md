## Zweck

Nach jedem Hineinzoomen musste die Gesamtstrecke von Hand wieder
zusammengesucht werden. Der Startausschnitt konnte das längst — `startAusschnitt()`
rahmt beim ersten Laden alle sichtbaren Strecken ein —, aber nur ein einziges Mal
pro Sitzung.

2.6.6 macht daraus einen Knopf: **ein Tipp, alle sichtbaren Strecken im Bild.**

## Was neu ist

**Der Knopf.** Links unter der Leaflet-Zoomleiste, 34 × 34 px — dieselbe
Außenbreite, derselbe Rahmen, dieselbe Rundung wie die Zoomknöpfe. Er sieht
aus wie deren dritter Knopf, und das ist Absicht: die linke obere Spalte ist die
einzige Stelle, die auf dem Handy und auf dem Desktop frei bleibt (oben Mitte
liegt die Rennleiste, unten die Reihe Optionen/Taktik, oben rechts auf dem
Desktop der Taktik-Knopf).

Das Symbol ist **kein Zeichen, sondern ein SVG** (vier Eckwinkel). Ein fehlendes
Glyph auf einem fremden Android-Font wäre im Rennen ein leerer weißer Knopf.

**Auto-Zoom wird beim Tippen abgeschaltet**, mit Hinweis „Auto-Zoom aus". Das
ist die eigentliche Entscheidung dieses Updates: `loadPositions()` läuft im
Sekundentakt und rahmt bei eingeschaltetem Auto-Zoom ab zwei frischen Trackern
jede Sekunde erneut das Feld ein. Ohne Abschalten wäre der Streckenausschnitt
nach spätestens einer Sekunde wieder weg — ein Knopf ohne sichtbare Wirkung.
Zurück geht es mit einem Tipp im Optionsmenü, dessen Beschriftung und Farbe
mitgeführt werden.

**Was eingerahmt wird:** die Strecken **aller sichtbaren Rennen**, wie beim
Startausschnitt. Abgewählte Rennen bleiben draußen.

**Ersatzweg vor dem GPX-Upload:** liegt keine Strecke vor, treten die frischen
Tracker (plus das eigene Teamauto) an ihre Stelle; ein einzelner bekommt Zoom 15.
Betreuer bleiben wie beim Auto-Zoom außen vor — einer an der Verpflegungszone
30 km abseits drückt das Feld sonst auf einen Punkt zusammen. Ist gar nichts da,
kommt der Hinweis „Keine Strecke geladen" und der Ausschnitt bleibt stehen.

**Im Streckenmodus tritt der Knopf zurück.** Die Leiste „Start/Ziel setzen" liegt
oben über die volle Breite und bricht auf dem Handy um; sie hätte den Knopf sonst
unter sich gehabt bzw. er über ihrem Eingabefeld gelegen. Das löst ein reiner
CSS-Geschwisterselektor — kein zusätzlicher Zustand in JavaScript.

Der Knopf ist für **alle sichtbar**, auch ohne Login: er ändert nichts am Rennen,
sondern nur den eigenen Bildausschnitt.

**NEU**

```js
// Die Streckenpunkte aller sichtbaren Rennen - die eine Stelle, an der
// diese Liste entsteht. Der Startausschnitt und der Knopf "Gesamte
// Strecke" rahmen dadurch garantiert dasselbe ein.
function streckenPunkteSichtbar() {
  const punkte = [];
  sichtbareRennenListe().forEach(id => {
    const coords = (typeof gpxByRace !== 'undefined') ? gpxByRace[id] : null;
    if (Array.isArray(coords)) coords.forEach(p => punkte.push(p));
  });
  return punkte;
}

// Der Knopf links unter der Zoomleiste. Anders als startAusschnitt()
// ohne Sperre - er darf beliebig oft.
//
// Auto-Zoom wird dabei abgeschaltet: er rahmt im Sekundentakt das Feld
// ein und haette den Streckenausschnitt nach spaetestens einer Sekunde
// wieder ueberschrieben. Ein Knopf ohne sichtbare Wirkung ist
// schlimmer als keiner. Zurueck geht es mit einem Tipp im Optionsmenue.
//
// Liegt keine Strecke vor - vor dem GPX-Upload -, treten die frischen
// Tracker an ihre Stelle. Betreuer bleiben wie beim Auto-Zoom
// draussen: einer an der Verpflegungszone 30 km abseits druckt das
// Feld auf einen Punkt zusammen.
function zoomAufStrecke() {
  let punkte = streckenPunkteSichtbar();
  if (punkte.length === 0) {
    punkte = Object.values(lastPositions).filter(p => !p.betreuer && !p.stale);
    if (teamCarMarker) {
      const tc = teamCarMarker.getLatLng();
      punkte.push([tc.lat, tc.lng]);
    }
  }
  if (punkte.length === 0) {
    if (typeof showToast === 'function') showToast('Keine Strecke geladen');
    return;
  }
  if (autoZoom) {
    setzeAutoZoom(false);
    if (typeof showToast === 'function') showToast('Auto-Zoom aus');
  }
  if (punkte.length === 1) map.setView(punkte[0], 15);
  else                     map.fitBounds(punkte, { padding: [40, 40] });
}

const fitBtnEl = document.getElementById('fitBtn');
if (fitBtnEl) fitBtnEl.addEventListener('click', zoomAufStrecke);

function startAusschnitt() {
  if (startAusschnittGesetzt) return;
  const punkte = streckenPunkteSichtbar();
  if (punkte.length === 0) return;
  startAusschnittGesetzt = true;
```
